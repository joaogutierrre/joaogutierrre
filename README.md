## 🧠 System Design

- 🏗️ **Monoliths & distributed systems** — hands-on experience with both: well-structured modular monoliths and event-driven services/workers, and knowing when each one is the right call
- 💥 **Design for failure** — circuit breakers, timeouts, retries with exponential backoff, idempotent consumers and graceful degradation as first-class concerns
- 📨 **Event-driven architecture** — CQRS, event sourcing, message brokers and at-least-once delivery semantics (dedupe, ordering, poison messages)
- 🔍 **Observability-first** — distributed tracing, structured logs and metrics with OpenTelemetry; designing telemetry contracts alongside the code
- ⚡ **Data & performance** — relational modeling and versioned migrations, caching strategies, full-text search engines and high-volume ingestion pipelines
